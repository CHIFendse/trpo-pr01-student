# Практическая работа №1. HTML и базовая CSS-разметка

Информационная страница курса ТРПО на чистых HTML и CSS. Страница собрана по данным из папки `data`.

## Технологии

- HTML5
- CSS3 (Flexbox, медиазапросы)

## Запуск

1. Склонировать репозиторий.
2. Открыть файл `index.html` в браузере (двойной клик или Live Server в VS Code).

Сборка и установка зависимостей не нужны.

## Структура проекта

```
index.html          страница
css/styles.css      стили
data/               исходные данные (content.csv, navigation.json)
images/             изображения (logo.svg, cover.svg)
dataset/            исходный dataset задания
```

## Использованные файлы dataset

- `navigation.json` — пункты меню. Каждый пункт ведёт на раздел с таким же id: `about`, `tracks`, `schedule`, `signup`.
- `content.csv` — 6 карточек в разделе «Направления» и 6 строк таблицы в разделе «Расписание». Данные перенесены вручную.
- `logo.svg` — логотип в шапке.
- `cover.svg` — изображение в разделе «О курсе».

## Структура HTML

- `header` — логотип и навигация `nav`.
- `main` — четыре раздела `section`:
  - «О курсе» — заголовок `h1`, описание и изображение;
  - «Направления» — карточки `article`;
  - «Расписание» — таблица с `caption`, `thead` и `tbody`;
  - «Регистрация» — форма.
- `footer` — подвал.

Иерархия заголовков: `h1` → `h2` у разделов → `h3` у карточек.

## Форма

- У каждого поля есть `label`, связанный через `for` и `id`.
- Типы полей: `text`, `email`, `tel`, `number`, `checkbox`, `select`, `textarea`.
- Ограничения: `required`, `minlength` и `maxlength` у имени, `maxlength` у комментария, `min="1"` и `max="6"` у курса.
- Ошибочное состояние: при пустых или неверных полях браузер не отправляет форму и показывает подсказку, а поле с ошибкой подсвечивается красной рамкой.

## CSS-приёмы

- `box-sizing: border-box` для всех элементов.
- Базовая типографика: шрифт, размер и межстрочный интервал.
- Ограничивающий контейнер `.container` шириной 1100px.
- Оформление ссылок и состояние `:focus-visible` для навигации с клавиатуры.
- Flexbox: шапка, навигация, блок «О курсе», карточки с переносом (`flex-wrap`) и поля формы.
- Медиазапрос `max-width: 720px`: шапка и блок «О курсе» выстраиваются в колонку.
- Таблица помещена в блок с `overflow-x: auto`, поэтому на узком экране нет горизонтальной прокрутки страницы.
- Стили задаются только классами, стилей внутри HTML нет.

## Проверка

1. Нажать «Расписание» в меню — страница прокручивается к таблице.
2. Уменьшить окно до 700px — карточки и шапка перестраиваются.
3. Отправить пустую форму — браузер показывает ошибку у обязательного поля.
4. Пройти по странице клавишей Tab — фокус виден на ссылках и полях.
