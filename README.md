# Практическая работа 1

Страница курса на HTML и CSS: меню, карточки, таблица, форма.

## Запуск

Открыть `index.html` в браузере.

## Dataset

- `navigation.json` — пункты меню, ведут на `about`, `tracks`, `schedule`, `signup`
- `content.csv` — 6 карточек и таблица
- `logo.svg`, `cover.svg` — картинки в шапке и в разделе «О курсе»

## HTML

`header` с `nav` → `main` с четырьмя `section` → `footer`. Карточки — `article`, таблица с `thead` и `tbody`, у полей формы есть `label`.

## CSS

`box-sizing: border-box`, `main` шириной 900px, рамка при `:focus`, Flexbox в шапке и у карточек, медиазапрос на 720px.
